# Shobhika 1.05

Unmodified regular and bold OpenType fonts from the official release:
https://github.com/Sandhi-IITBombay/Shobhika/releases/tag/v1.05

Distributed under the SIL Open Font License 1.1; see OFL.txt and Copyright.txt.
The app self-hosts these faces under the existing `Shobhika` family name so
saved boards and PDF exports use the same font, without a local installation.
